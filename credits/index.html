Licenses & credits

The receipts.

cmdlib is intended to be a paid product. That makes every borrowed idea, every dependency and every font a commercial decision, not a footnote. This page is the audit: what is used, under which license, and whether it can ship in paid software.

01

Commercial use first

A dependency only ships if its license permits commercial use with attribution. MIT, ISC and OFL do. GPL, AGPL, SSPL and non-commercial-only assets do not, so they are not bundled.

02

The linter is ours

cmdlib's lint engine is original TypeScript that shares the runtime's parser. Spyglass and mclint are credited as semantic references; neither codebase is vendored or copied.

03

No Minecraft assets

The hero art, logo, OG image and UI are original. No textures, sounds, models, fonts or wiki prose from Minecraft or the Minecraft Wiki are redistributed.

Standing on shoulders

Linting, and the tools before it.

How “compatible” is defined here

cmdlib parses mcfunction with the same 26.3 grammar it executes, reports spans and rule codes, and can export diagnostics as LSP-compatible JSON (severity, range, code, message, quick fixes). That output can be fed to editors and tooling that speak the Language Server Protocol. It does not embed Spyglass or mclint at runtime, which keeps the paid product free of copyleft obligations while still crediting the projects that established the conventions.

Minecraft.

cmdlib is an independent tool for building Minecraft: Java Edition datapacks. It is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft. Minecraft is a trademark of Mojang Synergies AB. References to game versions, pack formats and command names are nominative and descriptive.

The runtime is a deliberately limited reimplementation for authoring and preview. It is not a Minecraft server or client, and it does not contain Minecraft code or assets.
