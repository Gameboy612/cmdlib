Supported features

What works.

cmdlib is a datapack IDE with a real command simulator, NBT engine, scoreboard runtime and linter. This is the current surface — the commands, formats and tooling you can rely on today.

01 / Workbench

The editor around the pack.

Everything is client-side. Projects live in the browser, and the simulator runs the same functions you would run in game.

Dockable workbench

Explorer, code, console, preview, scoreboard and timeline panels. Float, maximize, close and reset them.

Code editor

CodeMirror with syntax highlighting, tabs, multi-file editing and context-aware completion.

Projects

Group several packs into one workspace, switch packs, import projects and export the whole project.

World preview

Inspect entities, positions, NBT, effects and inventories. Right-drag to rotate, scroll to zoom.

Console

Tab completion, history and log-level filters for errors, warnings, chat, data, commands and system messages.

Timeline

Play, pause, freeze, step, change tick rate and speed. Load tags, tick tags and scheduled functions are simulated.

Search all

Ctrl/Cmd + Shift + F searches every file with regex and case options, plus replace all. Ctrl/Cmd + P opens the file palette.

02 / Datapacks

Formats and versions.

Version-aware folders, pack metadata, macros, tags, predicates and multi-pack projects.

Versions

Minecraft 1.13 through 26.3, including pack-format and folder-layout migrations.

Pack metadata

Generate and update pack.mcmeta for legacy and modern versions.

Functions

Namespaced .mcfunction files, macros, function tags and load/tick tags.

Non-function tags

Item, block, entity type, fluid and game event tags.

Predicates

Datapack predicates with references, cycles and common condition types.

Player mode

Join as any username at permission level 0 with a restricted console, live inventory, item use and WASD movement. Operator panels are hidden.

Advancements

Criteria, display data, rewards and a dockable Advancements panel. Tick and inventory triggers run rewards automatically.

Items & components

Item IDs, 1.20.5+ components, stack counts, player slots, ender chests and item modifiers, with a dockable Inventory panel and right-click Use/Equip/book actions.

Imports

Local ZIP projects, GitHub repositories, nested packs and multi-pack archives.

Large archives

Up to 50,000 datapack files or 128 MB expanded; non-datapack assets are skipped before decompression.

Explorer scaling

Folders page 300 rows at a time so huge packs remain responsive.

04 / NBT & data

The data layer.

Storage, entity NBT, block NBT and the path vocabulary datapacks use in practice.

SNBT

Parse and print compounds, lists, strings, numbers and typed arrays.

Paths

Keys, quoted keys, indexes, wildcards, compound filters and negative indexes.

String slices

Negative start/end indexes and numeric-to-string conversion.

UUIDs

Int-array UUIDs, canonical and abbreviated UUID entity targets.

Execute store

Write results into scores, storage, entity NBT and block NBT.

Display matrices

Matrix-form display transformations with translation/scale normalized by homogeneous w.

Dates and numbers

Signed 32-bit scores, clamped values and numeric result semantics.

Predicates

all_of, any_of, inverted, reference, entity_properties, entity_present, location_check, score, entity_scores, random_chance, random_chance_with_looting, time_check, weather_check and value_check.

05 / Tooling

Feedback while you type.

Linting, completion and navigation are built into the editor and console.

Linting

Unknown commands, objectives, functions, tags, predicates and paths; unused functions; macro and folder errors. Bounded for large projects.

Autocomplete

Commands, selectors, objectives, functions, tags, storage, NBT, coordinates, blocks, items, entities and predicates.

Console completion

Command names, arguments, NBT paths and enabled trigger objectives.

Command palette

Ctrl/Cmd + K for file paths, function IDs like cmdlib:stats, panels and actions.

Keybindings

Custom reload, run, preferences and palette bindings.

Log filters

Show or hide errors, warnings, chat/tellraw, data, command echoes and system messages.

06 / Limits

What it is not.

cmdlib is a focused simulator, not a Minecraft client or server. These are the deliberate boundaries.

AreaBoundary
Command coverageCommands outside the supported list produce a warning and continue. They do not halt a function.
26.3 conditions/execute if slots is not simulated yet; /execute if items entity is.
Number providers/data modify … compute is not simulated yet.
World modelNo mob AI, collision, physics, pathfinding or full block rendering.
Chunks/forceload does not load real chunk data; it is a simulation no-op.
MediaSounds and particles are not rendered.
RenderingThe preview is an entity schematic, not a Minecraft client.
Linting budgetLinting stops after 2,000 function files, 200,000 commands or 3 seconds and reports lint-truncated.

Unsupported commands are warnings, not crashes.

A function that calls an unsupported command logs a warning and continues to the next line. Failed commands inside functions also continue silently, matching vanilla function execution. The linter still reports syntax and structural problems before you run.
